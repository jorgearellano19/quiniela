# M1.1 — Platform Operations and Authentication Security

## Status

`COMPLETED`

## Goal

Harden authentication before Competition development with narrowly scoped platform operations, operator-assisted recovery, session controls, auditability, and persistent rate limiting.

## In scope

- Better Auth global `platform_operator` role, separate from every Competition capability.
- Exact-email lookup, suspension/restoration, session revocation, and temporary-password issuance.
- CLI-only operator grant/revoke.
- Forced replacement of a server-generated 15-minute temporary password.
- PostgreSQL-backed auth rate limiting and focused non-E2E tests.

## Out of scope

- Competition authorization, default super-admin powers, impersonation, user deletion, arbitrary operator password assignment, email delivery, backup codes, 2FA, CAPTCHA, Redis, and E2E infrastructure.

## Dependencies and specifications

M1.1 depends on M1 and is the prerequisite for M2. The authoritative behavior is defined in the authentication sections of `docs/product/product-spec.md`, `docs/specs/application-use-cases.md`, `docs/specs/database-schema.md`, `docs/specs/implementation-spec.md`, and `docs/specs/testing-strategy.md`.

## Operational commands

Local operator role changes use the migrated development database configured by `.env.local`:

```bash
pnpm operator:grant --email <email> --actor <label> --reason <reason>
pnpm operator:revoke --email <email> --actor <label> --reason <reason>
```

Production execution must supply its deployment environment explicitly and must never reuse `.env.local` or test credentials.

## Acceptance criteria

- [x] Platform Operator receives no Competition authority.
- [x] Suspension revokes sessions and blocks authentication.
- [x] Temporary credentials expire and force permanent password replacement.
- [x] Sensitive authentication mutations are audited without secrets.
- [x] Credential endpoints have persistent rate limiting and safe 429 feedback.
- [x] Format, lint, typecheck, unit, integration, and build checks pass.
